# network

Network operations and interrogations.

- `pf/`: PF firewall toolkit wrappers and helpers.
- `router.sh`: router-facing checks and status snapshots.
- `sitechk/`: DNS, TLS, and HTTP identity verification utility.
- `wifiscan/`: native CoreWLAN-backed Wi-Fi scan utility.
