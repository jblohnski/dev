# apps

Standalone utilities that are best organized as self-contained directories.

Rules:

- Keep each tool in its own directory under `apps/`.
- Let structure drive grouping for file-backed commands when a real subdirectory exists.
- Preserve per-tool `README.md` files for local usage and requirements.
